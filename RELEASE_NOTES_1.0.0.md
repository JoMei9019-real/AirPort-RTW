# AirPort-RTW 1.0.0

First stable release of AirPort-RTW.

## Working
- Native macOS Wi-Fi integration through IO80211FamilyLegacy
- RTL8821CE verified
- RTL8822BE / RTL8822CE supported and awaiting broader hardware reports
- WPA2-Personal
- WPA2/WPA3 transition networks using WPA2
- Open networks
- 2.4 GHz and 5 GHz
- Native scanning and association
- CoreWiFi auto-join
- Network traffic with normal throughput
- Sleep / wake with macOS-managed reconnect

## Not yet supported
- WPA3-only
- Enterprise Wi-Fi
- Hidden networks
- AirDrop / Continuity / functional AWDL

Keep a bootable OpenCore EFI backup when testing kernel extensions.
